# Learning roadmap

Target: foundational skills for junior security analyst, security internship, or IT support opportunities.

Planning estimate: 24 study weeks, often 6–9 calendar months at 6–8 hours per week. Repeat topics as needed. All required study uses free resources; paid exams are excluded.

| Phase | Study weeks | Topics | Evidence to produce | Status |
| --- | --- | --- | --- | --- |
| Foundations | 1–4 | Computer basics, virtual machines, Linux commands, permissions, pipes | Lab inventory and Linux write-up | Planned |
| Networks | 5–8 | Layers, IPv4, subnetting, DNS, ports, TCP/UDP, Wireshark | Sanitized packet-analysis report | Planned |
| Systems and scripting | 9–12 | Windows logs, hardening, Python, synthetic log parsing | Hardening checklist and tested log analyzer | Planned |
| Security essentials | 13–16 | Risk, identity, hashing/encryption, authorized web labs | Risk register and web lab reports | Planned |
| SOC practice | 17–20 | Alert triage, timelines, detection logic, incident response | Sign-in investigation and tabletop report | Planned |
| Career launch | 21–24 | GitHub, reproducibility, troubleshooting, communication | Reviewed portfolio and capstone | Planned |

## Completion rule

Learn one concept, practice it, save the evidence, then explain it without following a walkthrough. Aim for at least 70% on knowledge checks and independently reproduce the practical result before marking a phase complete.
